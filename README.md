# Under the Oak Tree
L’amour est-il vraiment un conte de fées ?
Maximilienne, une jeune dame bègue, est forcée de se marier avec le seigneur Riftan, mais celui-ci part en campagne après leur nuit de noces. Trois ans plus tard, il revient triomphalement, prêt à la chérir. Mais leur histoire d’amour, bien qu’initiée par un mariage, sera loin d’être un conte de fées.
